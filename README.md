## Tareas de desarrollo cotidianas

- `// Refactor {a specific} file from {x} to {y}...`
  <sub>De propósito general, se aplica a cualquier idioma o repositorio.</sub>

- `// Add a test suite...`
  <sub>Útil para repositorios que carecen de cobertura de pruebas.</sub>

- `// Add type hints to {a specific} Python function...`
  <sub>Bases de código Python en transición a código tipificado.</sub>

- `// Generate mock data for {a specific} schema...`
  <sub>API, frontends o entornos con muchas pruebas.</sub>

- `// Convert these commonJS modules to ES modules...`
  <sub>Proyectos JS/TS que modernizan código heredado.</sub>

- `// Turn this callback-based code into async/await...`
  <sub>Bases de código JavaScript o Python que mejoran la lógica asincrónica.</sub>

- `// Implement a data class for this dictionary structure...`
  <sub>Útil para proyectos de Python que avanzan hacia un manejo de datos más estructurado con dataclasses o Pydantic.</sub>

## Depuración

- `// Help me fix {a specific} error...`
  <sub>Para cualquier repositorio en el que estés atascado en un error de ejecución o de compilación.</sub>

- `// Why is {this specific snippet of code} slow?`
  <sub>Perfiles de rendimiento para bucles, funciones o consultas.</sub>

- `// Trace why this value is undefined...`
  <sub>Errores de JS/TS en frontend y backend.</sub>

- `// Diagnose this memory leak...`
  <sub>Aplicaciones del lado del servidor o procesos de ejecución prolongada.</sub>

- `// Add logging to help debug this issue...`
  <sub>Útil para solucionar fallos silenciosos.</sub>

- `// Find race conditions in this async code`
  <sub>Sistemas concurrentes en JS, Python, Go, etc.</sub>

- `// Add print statements to trace the execution flow of this Python script...`
  <sub>Para depurar scripts complejos de Python o comprender comportamientos inesperados.</sub>

## Pruebas

- `// Add integration tests for this API endpoint`
  <sub>Aplicaciones Express, FastAPI, Django y Flask.</sub>

- `// Write a test that mocks fetch`
  <sub>Búsqueda del lado del navegador o lógica axios.</sub>

- `// Convert this test from Mocha to Jest`
  <sub>Migraciones de suites de pruebas JS.</sub>

- `// Generate property-based tests for this function`
  <sub>Código funcional o con mucha lógica.</sub>

- `// Simulate slow network conditions in this test suite`
  <sub>Aplicaciones web y móviles.</sub>

- `// Write a test to ensure backward compatibility for this function`
  <sub>Mantenedores de bibliotecas o SDK.</sub>

- `// Write a Pytest fixture to mock this external API call...`
  <sub>Para proyectos de Python que utilizan Pytest y necesitan simulaciones robustas para realizar pruebas.</sub>
